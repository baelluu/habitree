Технологии

Технический стек

Flutter + Dart
Мобильное приложение

Один код = Android + iOS. Нативная производительность. Dart легче, чем Kotlin + Swift параллельно.

PostgreSQL
Хранение данных

Проверенная реляционная СУБД. Простая схема: users, habits, habit_logs, food_logs.

FastAPI
REST API · Python

Быстрый старт, встроенная Swagger-документация. Популярен в индустрии.

Figma
UI / UX

Прототипы до кода → экономия времени на переделках. Индустриальный стандарт.

OpenFoodFacts
База продуктов

Бесплатная открытая база: 3+ млн продуктов, КБЖУ, без ключа.
